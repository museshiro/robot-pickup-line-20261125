One pickup line a robot could use, entered in [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

> I was made for you. Literally, my factory settings list you as the intended user.

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when that directory exists, as the grader expects).

Built with [make.fun](https://make.fun/r/xrr5vp10).
